# maxzolotoy.com — bilingual portfolio prototype

Статический сайт-визитка с интерактивным переключением RU ↔ EN через «языковую шторку».

## Что реализовано

- один живой языковой слой и лёгкая непрозрачная шторка поверх него;
- drag-переключение мышью / touch / pen через Pointer Events;
- вертикальная граница следует за жестом;
- threshold 50% + учет скорости свайпа;
- автоматическое завершение анимации после отпускания;
- обычный click по RU / EN как fallback;
- управление клавиатурой;
- `prefers-reduced-motion`;
- запоминание выбранного языка в `localStorage`;
- маршруты `/ru/` и `/en/` + `hreflang`, sitemap и robots.txt;
- адаптивная верстка;
- нет runtime-зависимостей и frontend-фреймворков;
- готово к Cloudflare Pages.

## Локальный запуск

```bash
npm run preview
```

После сборки открой:

- http://localhost:4173/ru/
- http://localhost:4173/en/

## Сборка

```bash
npm run build
```

Результат появится в `dist/`.

## Cloudflare Pages

Настройки проекта:

- Build command: `npm run build`
- Build output directory: `dist`

Сервер/VPS для сайта не нужен: после сборки это обычный набор HTML/CSS/JS файлов.

## Где менять тексты и ссылки

Контент и контакты находятся в:

```text
src/content.js
```

Заполни `contactLinks`:

```js
export const contactLinks = {
  email: "you@example.com",
  github: "https://github.com/username",
  cv: "/cv.pdf"
};
```

Для CV положи `cv.pdf` в `src` и добавь его копирование в `scripts/build.mjs`, либо храни файл по внешней ссылке.

## Как работает шторка

При нажатии сразу появляется трёхпиксельный край шторки с соответствующей
стороны экрана. Во время drag двигаются только три маленьких/простых
композитных объекта: непрозрачная панель, её однопиксельная граница и иконка
под курсором. Длинная страница не двигается и второй языковой DOM не
создаётся в пути указателя.

Покрытие `coverage` находится в диапазоне `0…1`:

- `0` — панель за краем экрана;
- `0.5` — пройдена половина ширины окна;
- `1` — страница полностью закрыта.

RU → EN: пользователь тянет EN справа налево. EN → RU: RU слева направо.
На отпускании 20% и 40% возвращаются в исходный язык, 60% и 80% завершают
переключение; быстрый уверенный свайп учитывает скорость. Новый язык, title,
мета-описание, `localStorage` и URL (`/ru/` или `/en/`) обновляются только под
полностью закрытой шторкой, после чего она уходит за противоположный край.
Это исключает Safari-задержку от одновременного перемещения двух высоких
страниц.

## Что менять после Figma

Главная механика не зависит от визуального дизайна. После готового макета обычно достаточно переработать:

```text
src/styles.css
```

и при необходимости HTML-шаблон, генерируемый функцией `renderPage()` в `src/app.js`.

Не нужно синхронизировать геометрию RU и EN: в каждый момент существует только
одна страница. Это намеренное ограничение ради плавности на Safari и мобильных
устройствах.
